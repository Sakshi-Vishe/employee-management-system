# Employee Management System (EMS)

## Features
- Employee management with Create, Read, Update, and Delete operations
- Separate Angular frontend and Spring Boot backend
- MySQL database integration
- Department and designation management
- REST API integration

## Prerequisites
- Java 17
- Node.js and npm
- Angular CLI
- MySQL

## Run Backend
cd ems
./mvnw spring-boot:run

## Run Frontend
cd frontend
npm install
ng serve

## Database
Configure your MySQL database credentials in the backend application configuration before running.
